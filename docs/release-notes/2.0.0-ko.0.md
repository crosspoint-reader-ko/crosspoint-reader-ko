## 요약

upstream **v2.0.0**을 병합한 한국어 버전입니다. 형광펜과 발췌, 블루투스 페이지 넘김기 통합, SD 카드 플러그인, OPDS 2.0, 더 정교한 EPUB 조판이 들어왔습니다. 한국어 글꼴·조판 기능과 한국어 TXT 리더는 그대로 유지했습니다.

> [!IMPORTANT]
> **기본 본문 글꼴이 Pretendard 14pt에서 10pt로 바뀌었습니다.** 펌웨어에 내장한 글꼴은 이제 Pretendard 10pt 하나입니다. 지금까지처럼 14pt로 읽으려면 이 릴리스의 `Pretendard-14.epdfont`를 SD 카드 `/fonts`에 복사하고 설정 → 리더 → 글꼴 설정에서 고르세요. SD 글꼴을 이미 쓰고 있다면 바뀌는 것이 없습니다.

> [!NOTE]
> **페이지 캐시 형식이 바뀌어 모든 책이 처음 열 때 한 번 다시 조판됩니다.** 첫 페이지가 평소보다 늦게 뜨는 것은 정상입니다.

## upstream v2.0.0 주요 변경 사항

### 기능
* **형광펜과 발췌**: EPUB에서 글을 선택해 강조하고 발췌로 저장합니다. 버튼 기기는 리더 메뉴에서, 터치 기기는 단어를 길게 눌러 선택 손잡이를 끌어 고릅니다. 선택한 구절은 사전 검색에도 쓰입니다(여러 단어 포함).
* **블루투스 페이지 넘김기**: 설정 → 연결 → 블루투스 페이지 터너에서 리모컨을 찾고 연결하고 버튼을 지정합니다. 짧게·길게 누르기에 페이지 넘김, 장 이동, 리더 메뉴, 발췌 선택을 따로 줄 수 있습니다.
* **SD 카드 플러그인**: 책 카탈로그·다운로드, 기기 웹 화면 도구를 플러그인으로 더합니다. 설정 → 연결 → 플러그인에서 켜면 홈에 나타납니다.
* **EPUB 조판 개선**: 첫 글자 장식(드롭 캡), 작은 대문자, 섞인 글자 크기, 테두리와 음영 상자, 표의 셀 여백과 테두리를 반영합니다. 제목이 다음 문단과 떨어지지 않습니다. 정지 GIF 그림(표지 포함)을 보여 줍니다.
* **줄 간격 7단계**: 0%부터 +75%까지 고릅니다. 이전의 좁게/보통/넓게/아주 넓게는 가장 가까운 단계로 옮겨집니다.
* **흑백 그림**: 설정 → 리더 → 이미지에 "흑백"이 생겼습니다. 그림을 흑백 점묘로 그려 이미지 페이지도 전체 새로 고침 없이 넘어갑니다. 1.6.5-ko.11의 `이미지 회색 표시`를 끈 상태는 이 설정으로 옮겨집니다.
* **OPDS 2.0** 카탈로그, OPDS·KOReader 동기화의 사용자 지정 HTTP 헤더, KOReader 동기화 서버 프로필.
* **JPEG 그림 보기**: 파일 탐색기에서 `.jpg`를 엽니다.
* 새 설정 화면 묶음, 새 기기 웹 화면, 터치 기기의 밀어서 삭제.
* **새 기기**: Metalio E-Ink 4, EEGO A4, BOOX Picco용 한국어 펌웨어도 함께 배포합니다.

### 수정 / 성능
* 장이 수천 개인 책의 색인이 중간에 멈추던 문제, 링크를 따라갔다 돌아올 때 페이지가 바뀌던 문제를 고쳤습니다.
* 책을 다시 열 때 힙이 묶이던 문제, 메모리가 적을 때 CSS 스타일을 잃던 문제를 고쳤습니다.
* ZIP 목록을 한 번에 읽고 페이지 위치를 묶어 읽어 책 열기가 빨라졌습니다.
* X3 안티앨리어싱 멈춤, X3 배터리 용량 표시를 고쳤습니다.

## 한국어 버전 변경 사항

### 기능
* **갈래목(Gallaemok DOS) 홈 테마** (설정 → 화면 → UI 테마). MS-DOS 화면처럼 최근 책 최대 4권과 메뉴를 글자로 보여 줍니다. 최근 책마다 읽은 비율이 나오고, 표지를 불러오지 않습니다. 저장소의 삼국지3 한국어 글꼴 [`assets/fonts/Sam3_23.epdfont`](https://github.com/crosspoint-reader-ko/crosspoint-reader-ko/blob/2.0.0-ko.0/assets/fonts/Sam3_23.epdfont)(Sam3KRFont, 이담허, MIT)를 SD 카드에 넣고 설정 → 화면 → 시스템 글꼴 (UI)에서 고르면 더 DOS답게 보입니다. 글꼴 없이도 동작합니다. (meat-holic, #29)

### 바뀐 동작
* **내장 글꼴은 Pretendard 10pt 하나입니다.** UI와 기본 본문 글꼴로 함께 씁니다. 한글 전체와, KoPub 바탕에서 가져온 한자를 담고 있습니다. 14pt는 펌웨어 크기 때문에 뺐고 릴리스 파일 `Pretendard-14.epdfont`로 제공합니다.
* **마크다운(`.md`)은 EPUB 리더로 엽니다.** 줄마다 문단으로 나뉘어 들여쓰기와 문단 간격이 줄마다 적용됩니다. TXT는 아래처럼 한국어 TXT 리더로 엽니다.

### 유지된 한국어 전용 기능
* **한국어 TXT 리더**: upstream은 TXT를 EPUB 리더로 엽니다. 그러면 파일 전체가 한 장이 되어 % 이동 때마다 파일 전체를 다시 조판합니다(큰 TXT에서 3분 가까이). 한국어 버전은 바이트 위치로 페이지를 나누는 TXT 리더를 그대로 써서 % 이동이 바로 됩니다. 길게 눌러 여러 쪽 이동, 읽기 시간, 읽던 위치도 그대로입니다.
* `UnifiedFontFamily` / `SdFontFamily` 글꼴 시스템 (SD 카드 `.epdfont` 런타임 로딩, 설정 → 리더 → 글꼴 설정)
* 합성 볼드 렌더링, 자간 조절
* 첫 줄 들여쓰기 켜기/끄기와 글자 단위 줄바꿈(기본 켜짐). upstream의 칸 수 들여쓰기 설정과 함께 있고, 들여쓰기를 켜면 그쪽이 쓰입니다.
* 하이픈은 글자 단위 줄바꿈이 꺼져 있을 때만 적용
* 사전 검색의 한국어 어간 찾기(활용형 → 기본형)
* 읽기 시간 누적·초기화, 읽기 옵션 메뉴, 절전 이미지 선택
* X4 2단계 OTA (SD에 내려받은 뒤 플래시), X4 Pro 터치 메뉴

### 포함하지 않은 upstream 기능
* `.cpfont`·TTF SD 글꼴 엔진, 글꼴 다운로드(Noto Serif, Libron), 텍스트 설정 화면, 웹 글꼴 페이지 (한국어 `.epdfont` 엔진 유지)
* 다른 UI 언어 (한국어·영어만 포함)

자세한 상충 지점과 처리 내용: `docs/release-notes/2.0.0-ko.0-merge-conflicts.md`
