## 요약

리모컨을 두 대 이상 페어링했을 때 책에서 블루투스 리모컨이 연결되지 않던 문제를 고쳤습니다.

## 한국어 버전 변경 사항

### 수정
* **책을 열면 페어링된 리모컨을 모두 차례로 찾습니다.** 지금까지는 마지막으로 페어링한 리모컨 한 대만 찾아서, 그 리모컨이 꺼져 있으면 다른 리모컨이 켜져 있어도 "블루투스 연결 실패"가 떴습니다. 예를 들어 BOOX Keypage를 먼저, 미테르 리모컨을 나중에 페어링하면 책에서 Keypage가 붙지 않았습니다. 이제 설정 화면처럼 먼저 켜진 리모컨이 연결됩니다.
  * 꺼진 리모컨은 8초 뒤 다음 리모컨으로 넘어가므로, 켜진 리모컨은 늦어도 십몇 초 안에 붙습니다.

### 업데이트 방법

- **OTA**: WiFi 연결 후 설정 → 시스템 → 업데이트
- **SD**: X3/X4는 `firmware.bin`, 다른 기기는 `crosspoint-1.6.5-ko.8-<기기>.bin`을 SD 카드에 복사 → 설정 → 시스템 → SD카드 펌웨어 업데이트
- **웹 플래셔**: https://crosspoint.kr/flasher
- 설치 가이드: https://crosspoint.kr/install

KoPub 바탕 SD 글꼴(`KoPubBatang-14.epdfont`)은 이번 릴리스에도 들어 있습니다.

**전체 변경 사항**: https://github.com/crosspoint-reader-ko/crosspoint-reader-ko/compare/1.6.5-ko.7...1.6.5-ko.8
