## 요약

X4 Pro에서 그림이 있는 EPUB 페이지의 글자가 거칠게 나오고 두세 번 깜박이던 문제를 고쳤습니다. 그림을 흑백으로 그려 깜박임 없이 넘기는 `이미지 회색 표시` 옵션도 더했습니다. SD 글꼴 KoPub 바탕은 그리스 문자를 제대로 보여 줍니다.

## 한국어 버전 변경 사항

### 수정
* **X4 Pro 이미지 페이지에서도 글자가 부드럽게 나옵니다.** 그림이 있는 페이지는 회색 단계를 다른 방식으로 그리는데, 이때 글자를 흑백으로만 그려 안티앨리어싱이 빠졌습니다. 이제 글자도 회색 가장자리를 함께 그립니다.
* **X4 Pro 이미지 페이지의 깜박임을 한 번 줄였습니다.** 그림 없는 페이지를 먼저 띄우던 단계와 주기적인 반쯤 새로 고침을 뺐습니다. 이제 이미지 페이지는 빠른 새로 고침 한 번과 회색 표시 한 번으로 넘어갑니다. 직접 새로 고침을 요청하면 전처럼 깨끗이 지웁니다.
* **KoPub 바탕 SD 글꼴(`KoPubBatang-14.epdfont`)이 그리스 문자를 보여 줍니다.** 악센트가 붙은 그리스어(ἄνδρα, μῆνιν)는 빈칸으로 나오고, 악센트 없는 글자는 전각이라 한 단어 안에서 띄어져 보였습니다. 그리스 문자는 모두 Noto Serif에서 가져와 한 단어가 한 글꼴로 이어집니다. 음표(♩♪), ①·ⅰ 같은 KS X 1001 기호도 이제 들어 있습니다.

### 기능
* **이미지 회색 표시** (설정 → 리더, 기본 켜짐). 그림을 회색 단계로 보여 주려면 이미지 페이지마다 화면 전체가 한 번 더 깜박입니다. 이 옵션을 끄면 그림을 흑백 점묘로 그려 이미지 페이지도 글자 페이지처럼 넘어갑니다. 회색 단계는 점의 밀도로 남고, 글자 안티앨리어싱은 그대로입니다.

### 업데이트 방법

- **OTA**: WiFi 연결 후 설정 → 시스템 → 업데이트
- **SD**: X3/X4는 `firmware.bin`, 다른 기기는 `crosspoint-1.6.5-ko.11-<기기>.bin`을 SD 카드에 복사 → 설정 → 시스템 → SD카드 펌웨어 업데이트
- **웹 플래셔**: https://crosspoint.kr/flasher
- 설치 가이드: https://crosspoint.kr/install

KoPub 바탕 SD 글꼴(`KoPubBatang-14.epdfont`)은 이번 릴리스에도 들어 있습니다. 그리스 문자 수정을 받으려면 SD 카드의 글꼴 파일을 새것으로 바꾸세요.
