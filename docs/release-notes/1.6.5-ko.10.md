## 요약

사전에서 한국어 단어를 찾을 수 있게 했습니다. 본문에 나온 모양 그대로(사랑을, 먹었다, 아름다운) 골라도 사전의 기본형(사랑, 먹다, 아름답다)을 찾아 보여 줍니다. 표준국어대사전을 기기용으로 변환한 사전 파일도 이번 릴리스에 함께 올립니다.

## 한국어 버전 변경 사항

### 기능
* **한국어 단어를 기본형으로 찾습니다.** 지금까지는 고른 단어를 글자 그대로만 찾아서, 조사나 어미가 붙은 한국어 단어는 거의 찾지 못했습니다. 이제 찾지 못하면 다음 순서로 다시 찾습니다.
  * 조사 떼기: 사랑을 → 사랑, 학생들이 → 학생, 집에 → 집
  * 용언의 기본형: 먹었다 → 먹다, 공부했다 → 공부하다, 간다 → 가다, 누워 → 눕다
  * 불규칙 활용: 아름다운 → 아름답다, 몰라 → 모르다, 파란 → 파랗다, 드문 → 드물다
  * 사전 화면 위쪽에 실제로 찾은 표제어가 나오므로 어떤 단어의 뜻인지 알 수 있습니다.
  * 『데미안』 본문의 단어 12,508가지로 시험해 고유 명사 13개를 빼고 모두 표제어를 찾았습니다. 규칙으로 짐작하기 때문에 가끔 다른 단어로 찾기도 합니다(예: 물을 → 물다).
* **표준국어대사전 사전 파일** (`stdict-korean-dictionary.zip`, 이번 릴리스 첨부). 단어 287,761개의 품사, 한자, 뜻풀이가 들어 있습니다(용례 제외).
  1. ZIP을 풀어 `stdict` 폴더를 SD 카드의 `/dictionaries/` 안에 넣습니다(`/dictionaries/stdict/stdict.ifo`가 되도록).
  2. 설정에서 사전으로 `표준국어대사전`을 고릅니다. 처음 한 번은 기기가 색인을 만드느라 시간이 걸립니다.
  3. 책에서 리더 메뉴의 사전을 열고 단어를 고릅니다.
  * 출처: 국립국어원 표준국어대사전, 크리에이티브 커먼즈 저작자표시-동일조건변경허락 2.0 대한민국 라이선스. 2026년 6월 데이터로 만들었습니다.
  * 직접 다시 만들려면 펌웨어 저장소의 `scripts/build_korean_dictionary.py`를 쓰세요.

### 업데이트 방법

- **OTA**: WiFi 연결 후 설정 → 시스템 → 업데이트
- **SD**: X3/X4는 `firmware.bin`, 다른 기기는 `crosspoint-1.6.5-ko.10-<기기>.bin`을 SD 카드에 복사 → 설정 → 시스템 → SD카드 펌웨어 업데이트
- **웹 플래셔**: https://crosspoint.kr/flasher
- 설치 가이드: https://crosspoint.kr/install

KoPub 바탕 SD 글꼴(`KoPubBatang-14.epdfont`)은 이번 릴리스에도 들어 있습니다.
