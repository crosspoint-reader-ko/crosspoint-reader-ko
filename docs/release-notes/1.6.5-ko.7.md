## 요약

X4·X3에서 블루투스 페이지 터너를 켤 때 메모리 여유를 더 확보하고, 켜는 동안 실패 문구가 잘못 보이던 문제를 고쳤습니다.

## 한국어 버전 변경 사항

### 수정
* **블루투스를 켜기 전에 SD 글꼴 캐시를 비웁니다.** SD 글꼴(예: KoPub 바탕 `KoPubBatang-14.epdfont`)로 읽고 있으면 글자 그림 캐시가 최대 32 KB를 잡고 있었는데, 이제 블루투스를 켜기 직전에 비웁니다. X4에서 켤 때마다 13~22 KB가 더 확보되는 것을 확인했습니다. 캐시는 다음 페이지를 그릴 때 다시 채워집니다.
* **설정 → 블루투스에서 켜는 동안 "블루투스를 켜지 못했습니다"가 보이던 문제.** 켜는 동안에는 "블루투스 켜는 중..."을 보여 주고, 실제로 실패했을 때만 실패 문구를 띄웁니다.

### 업데이트 방법

- **OTA**: WiFi 연결 후 설정 → 시스템 → 업데이트
- **SD**: X3/X4는 `firmware.bin`, 다른 기기는 `crosspoint-1.6.5-ko.7-<기기>.bin`을 SD 카드에 복사 → 설정 → 시스템 → SD카드 펌웨어 업데이트
- **웹 플래셔**: https://crosspoint.kr/flasher
- 설치 가이드: https://crosspoint.kr/install

KoPub 바탕 SD 글꼴(`KoPubBatang-14.epdfont`)은 이번 릴리스에도 들어 있습니다.

**전체 변경 사항**: https://github.com/crosspoint-reader-ko/crosspoint-reader-ko/compare/1.6.5-ko.6...1.6.5-ko.7
