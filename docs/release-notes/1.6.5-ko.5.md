## 요약

투명 절전 화면에서도 **절전 화면 선택**으로 쓸 그림을 고를 수 있습니다.

## 한국어 버전 변경 사항

### 수정
* **절전 화면 선택이 절전 화면 모드를 따릅니다.**
  * 절전 화면이 **투명**이면 `/.sleep-overlay`, `/sleep-overlay` 폴더의 BMP·PNG 오버레이를 보여 주고 고를 수 있습니다. PNG도 미리보기로 나옵니다.
  * 다른 모드에서는 지금처럼 `/.sleep`, `/sleep` 폴더의 BMP를 보여 줍니다.
  * 두 모드의 선택은 따로 저장됩니다. 한쪽에서 선택 화면을 열어도 다른 쪽 선택이 지워지지 않습니다.
  * 투명 절전 화면은 고른 오버레이 중에서 무작위로 나옵니다. 하나도 고르지 않았으면 폴더의 모든 오버레이를 씁니다.

### 업데이트 방법

- **OTA**: WiFi 연결 후 설정 → 시스템 → 업데이트
- **SD**: X3/X4는 `firmware.bin`, 다른 기기는 `crosspoint-1.6.5-ko.5-<기기>.bin`을 SD 카드에 복사 → 설정 → 시스템 → SD카드 펌웨어 업데이트
- **웹 플래셔**: https://crosspoint.kr/flasher
- 설치 가이드: https://crosspoint.kr/install

블루투스 페이지 터너와 기본 글꼴 변경은 [1.6.5-ko.4 릴리스 노트](https://github.com/crosspoint-reader-ko/crosspoint-reader-ko/releases/tag/1.6.5-ko.4)를 보세요. KoPub 바탕 SD 글꼴(`KoPubBatang-14.epdfont`)은 이번 릴리스에도 들어 있습니다.

**전체 변경 사항**: https://github.com/crosspoint-reader-ko/crosspoint-reader-ko/compare/1.6.5-ko.4...1.6.5-ko.5
