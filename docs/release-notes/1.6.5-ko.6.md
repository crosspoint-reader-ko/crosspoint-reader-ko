## 요약

절전 화면 그림을 한곳에서 관리합니다. **사용자 지정**과 **투명** 모드가 같은 그림과 같은 선택을 쓰고, PNG 배경화면도 쓸 수 있습니다.

## 한국어 버전 변경 사항

### 기능
* **절전 그림 하나로 합침**
  * `/.sleep`, `/sleep`, `/.sleep-overlay`, `/sleep-overlay` 폴더의 BMP·PNG를 한 목록으로 봅니다. 폴더 사이에 우선순위는 없습니다.
  * **절전 화면 선택**은 모드와 상관없이 같은 목록과 같은 선택을 보여 줍니다. 고른 그림이 있으면 그중에서, 없으면 전체에서 무작위로 고릅니다.
  * 모드는 그리는 방식만 정합니다. 사용자 지정은 화면을 그림으로 바꾸고, 투명은 읽던 페이지 위에 겹칩니다. 페이지는 PNG의 투명한 부분으로만 보입니다.
  * 루트의 `sleep.bmp`/`sleep.png`(사용자 지정), `sleep-overlay.bmp`/`sleep-overlay.png`(투명)는 전처럼 폴더보다 우선합니다.
* **사용자 지정 모드에서 PNG 배경화면을 쓸 수 있습니다.** 투명한 부분은 흰색으로 채웁니다.
* **절전 화면 선택 미리보기가 실제 절전 화면과 똑같이 나옵니다.** 절전 화면의 렌더러로 전체 화면에 그리고(맞춤/자르기, 필터, 회색조), 선택 표시와 버튼 안내를 그 위에 얹습니다. 투명 모드는 흰 바탕 위에 겹쳐 보여 줍니다.
* **터치 기기(X4 Pro):** 그림 오른쪽 절반을 탭하면 다음 장, 왼쪽 절반은 이전 장입니다. 선택은 아래 "선택됨" 띠를 탭해 바꿉니다.

### 수정
* 투명 모드에서 그림이 `/sleep`에만 있으면 기본 로고가 나오던 문제
* 선택을 바꿀 때마다 그림 전체를 다시 그려 여러 번 깜빡이던 문제. 이제 선택 표시만 바꿉니다.
* X4 Pro에서 리더를 쓰다가 재울 때 PNG를 메모리 부족으로 그리지 못할 수 있던 문제(PSRAM을 계산에 넣음)

### 업데이트 방법

- **OTA**: WiFi 연결 후 설정 → 시스템 → 업데이트
- **SD**: X3/X4는 `firmware.bin`, 다른 기기는 `crosspoint-1.6.5-ko.6-<기기>.bin`을 SD 카드에 복사 → 설정 → 시스템 → SD카드 펌웨어 업데이트
- **웹 플래셔**: https://crosspoint.kr/flasher
- 설치 가이드: https://crosspoint.kr/install

KoPub 바탕 SD 글꼴(`KoPubBatang-14.epdfont`)은 이번 릴리스에도 들어 있습니다.
