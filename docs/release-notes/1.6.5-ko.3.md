## 요약

1.6.5-ko.2의 수정 릴리스입니다. KOReader 동기화에서 퍼센트로만 저장된 진도(Calibre-Web NextGen 웹 리더 등)를 받아오도록 고쳤습니다.

## upstream 변경 사항

* **KOReader 동기화**: 진도를 조회할 때 퍼센트 진도도 받을 수 있다고 서버에 알립니다(`position_kinds=locator,percentage`). Calibre-Web NextGen이나 CWA의 웹 리더처럼 위치 정보 없이 퍼센트만 저장하는 서버에서도 진도를 받아옵니다. 퍼센트만 있는 진도는 해당 위치의 페이지로 대략 이동합니다. 이 파라미터를 모르는 일반 kosync 서버는 그대로 동작합니다. (upstream #3219, @mehalter, 이슈 #28 @runwithgit)

### 업데이트 방법

- **OTA**: WiFi 연결 후 설정 → 시스템 → 업데이트
- **SD**: X3/X4는 `firmware.bin`, 다른 기기는 `crosspoint-1.6.5-ko.3-<기기>.bin`을 SD 카드에 복사 → 설정 → 시스템 → SD카드 펌웨어 업데이트
- **웹 플래셔**: https://crosspoint.kr/flasher
- 설치 가이드: https://crosspoint.kr/install
