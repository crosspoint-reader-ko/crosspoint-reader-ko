# 2.0.0-ko.0 upstream merge decisions

Upstream tag `2.0.0` merged into `release/korean` (previous base 1.6.5). Korean invariants from `.claude/CLAUDE.md` are kept.

## Taken from upstream

- Markdown opens in the EPUB reader through upstream's pipeline (#3704).
- Seven line-spacing steps (`LINE_SPACING_100..175`). Old Korean saves (`lineSpacing` 0..3 = 1.00/1.20/1.40/1.60) migrate to the nearest step.
- Black & White images as the fourth Images option. The 1.6.5-ko.11 `imageGrayscale = 0` migrates to `IMAGES_DISPLAY_BW`.
- Settings grouping, clippings, plugins, OPDS2, new boards, mixed text sizes, drop caps, solid-block glyph fallback, `paragraphIndentSpaces`.
- Sleep image rotation uses upstream's full-period LCG (no repeats until every image is shown). The Korean selection filter (Sleep Image Selection) is kept on top.
- Dictionary word selection uses upstream's shared selection screen. The Korean stem fallback (`koreanstem::variants`) is kept in `Dictionary::lookup`.

## Kept from the Korean fork

- Korean SD font engine (`.epdfont`, `UnifiedFontFamily`, `SdFontFamily`, `FontSelectionActivity`). Upstream's `.cpfont`/TTF engine, font installer, font download and Text Settings screen are not taken. `GfxRenderer` has no-op `isSdCardFont` / `ensureSdCardFontReady` so shared code compiles.
- One built-in font, Pretendard 10pt, for the UI and as the default reader font, Korean and English only. It carries all Hangul syllables and, from KoPub Batang, the Hanja (what the 1.6.5 Pretendard 14 reader font had). Pretendard 14 is dropped: upstream 2.0.0 with both fonts was 113,648 bytes over the 0x640000 OTA slot, and 14pt was too large as the UI font. gh_release is 5,161,872 bytes (1,391,728 under). The reader font id changes, so cached sections rebuild.
- `paragraphIndent` toggle and `characterWrap` next to upstream's `paragraphIndentSpaces`. With the toggle on, the space-based indent is not used. Hyphenation only when `characterWrap == 0`.
- Section file version 100 (Korean numbering restarts above upstream's 73). Header: upstream v73 fields plus `paragraphIndent` and `characterWrap`.
- Reader Options menu row, reading timer, Bluetooth row shown whenever the radio is compiled in.
- The Korean TXT reader (`TxtReaderActivity`, offset-based, no whole-file layout). Upstream sends TXT through the EPUB reader as one chapter, and a percent jump there re-laid out the whole file (about 3 minutes on a large TXT on X4). `Txt` keeps upstream's static helpers and gets the reader's instance API back; TXT caches stay in `txt_<hash>`.
- Two-phase OTA (download to SD, then flash) and the Korean release asset names.

## Korean changes on top of upstream code

- `TxtToHtml` writes each Markdown line as its own `<p>` so paragraph indent and spacing apply per line (upstream used `<br />`, which only indented the first line of the file). Cache tag `TXT_CACHE_VERSION: 1-ko.1` rebuilds old Markdown caches.
- Dev build (`env:default`) only: `CROSSPOINT_NO_SLEEP_ON_USB` keeps the device awake while USB is connected. Temporary.
