## 요약

블루투스 페이지 터너(리모컨)로 책장을 넘길 수 있습니다. 블루투스가 들어갈 자리를 만들려고 기본 본문 글꼴을 KoPub 바탕에서 Pretendard로 바꿨습니다. 한자를 비롯해 이전 기본 글꼴에 있던 글자는 모두 그대로 표시됩니다.

## upstream 변경 사항

* **블루투스 페이지 터너** (upstream #3785, @martinqnguyen, @itsthisjustin): 책을 읽는 동안 블루투스 리모컨으로 페이지와 장을 넘깁니다. 모든 기기(X3/X4, X4 Pro, X4C, Sticky, PaperMono)에서 동작합니다.
  * 설정 → 시스템 → **블루투스 페이지 터너**에서 켜고, **리모컨 찾기**로 연결합니다. **등록된 리모컨**에서 지울 수 있습니다.
  * 화살표, Page Up/Down, Space, Enter, 볼륨 키를 보내는 리모컨은 바로 동작합니다. 다른 버튼은 리모컨을 연결한 채 **버튼 설정**에서 원하는 동작(다음/이전 페이지, 다음/이전 장, 확인, 뒤로, 리더 메뉴)을 고르고 버튼을 누르면 저장됩니다. 0.7초 이상 길게 누르면 짧게 누르기와 따로 저장됩니다.
  * 책을 열면 제목 자리에 "블루투스 연결 중…"이 나오고, 연결되면 제목이 돌아옵니다. 20초 안에 연결되지 않으면 "블루투스 연결 실패"가 나옵니다.
  * 블루투스는 책을 펼쳐 둔 동안에만 켜지고, 장을 새로 색인하는 동안과 화면을 바꿀 때는 잠시 꺼집니다. 그사이 누른 버튼은 무시됩니다. 연결된 리모컨이 없으면 30초 뒤 꺼지고, 책을 다시 열면 켜집니다.
  * 리더 메뉴와 툴바의 **더 보기**에서도 켜고 끌 수 있습니다.

## 한국어 버전 변경 사항

### 글꼴
* **기본 본문 글꼴이 Pretendard로 바뀌었습니다.** 한글과 영문은 Pretendard로, 한자와 Pretendard에 없는 기호는 KoPub 바탕으로 그립니다. 이전 기본 글꼴(KoPub 바탕)에 있던 글자 16,220자를 모두 포함합니다.
* **KoPub 바탕으로 계속 읽으려면** 이 릴리스의 `KoPubBatang-14.epdfont`를 SD 카드의 `/fonts` 폴더에 복사하고, 설정 → 리더 → 글꼴 설정에서 고르세요.
* 업데이트 뒤 책을 처음 열 때는 글꼴이 바뀌어 색인을 다시 만듭니다.

### 수정
* **리모컨 버튼 설정**: 일부 리모컨에서 버튼이 `2:2=00`처럼 저장되어 다시 켜면 설정이 사라지던 문제, `0x1C`처럼 저장된 버튼이 한 번만 동작하고 멈추던 문제를 고쳤습니다.
* 블루투스 화면을 한국어로 옮겼습니다.

### 업데이트 방법

- **OTA**: WiFi 연결 후 설정 → 시스템 → 업데이트
- **SD**: X3/X4는 `firmware.bin`, 다른 기기는 `crosspoint-1.6.5-ko.4-<기기>.bin`을 SD 카드에 복사 → 설정 → 시스템 → SD카드 펌웨어 업데이트

- 설치 가이드: https://crosspoint.kr/install
