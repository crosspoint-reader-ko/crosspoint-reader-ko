## 요약

블루투스 페이지 터너를 켜 둔 채 리모컨 없이 책을 읽으면 장이 넘어갈 때 재부팅되던 문제와, 이미지 페이지가 여러 번 깜박이던 문제를 고쳤습니다. 긴 장을 읽을 때 메모리 사용도 줄였습니다.

## 한국어 버전 변경 사항

### 수정
* **장이 넘어갈 때 재부팅되던 문제를 고쳤습니다.** 페이지 터너 옵션을 켜 두고 리모컨이 없는 상태에서 새 장을 펼치면 `assert failed: npl_freertos_sem_release`로 재부팅되고, 다시 켜도 같은 곳에서 반복됐습니다. 장을 만드는 동안 메모리를 확보하려고 블루투스를 끌 때 블루투스 라이브러리(NimBLE)의 종료 처리가 같은 콜백을 끝없이 불러 생긴 문제입니다. 빌드할 때 라이브러리를 고쳐 이 상황이 생기지 않게 했습니다.
* **이미지 페이지가 여러 번 깜박이던 문제를 고쳤습니다.** 책을 열고 블루투스가 연결되거나 연결에 실패해 상태바 문구가 바뀌면 페이지 전체를 다시 그려서 이미지가 두세 번, 많게는 네 번 깜박였습니다. 이제 아래쪽 상태바만 다시 그립니다.

### 성능 (upstream에서 가져옴)
* **장 나누기를 쉬는 시간에 끝까지 마칩니다** ([crosspoint-reader#4040](https://github.com/crosspoint-reader/crosspoint-reader/pull/4040)). 지금까지는 다섯 페이지씩만 미리 만들어 두고 나머지 동안 파서를 메모리에 들고 있었습니다. 이제 버튼을 누르지 않는 동안 장을 끝까지 나누고 파서를 바로 놓아 줍니다. 버튼을 누르면 곧바로 멈춥니다.
  * 페이지가 아주 많은 장에서 큰 메모리 덩어리를 한 번에 잡지 않게 바꿔, 긴 장 깊숙이 읽다가 재부팅되던 경우도 막았습니다.
* 쓰이지 않던 메모리 정리 호출을 걷어 냈습니다 ([crosspoint-reader#4094](https://github.com/crosspoint-reader/crosspoint-reader/pull/4094)).

### 업데이트 방법

- **OTA**: WiFi 연결 후 설정 → 시스템 → 업데이트
- **SD**: X3/X4는 `firmware.bin`, 다른 기기는 `crosspoint-1.6.5-ko.9-<기기>.bin`을 SD 카드에 복사 → 설정 → 시스템 → SD카드 펌웨어 업데이트
- **웹 플래셔**: https://crosspoint.kr/flasher
- 설치 가이드: https://crosspoint.kr/install

KoPub 바탕 SD 글꼴(`KoPubBatang-14.epdfont`)은 이번 릴리스에도 들어 있습니다.

**전체 변경 사항**: https://github.com/crosspoint-reader-ko/crosspoint-reader-ko/compare/1.6.5-ko.8...1.6.5-ko.9
