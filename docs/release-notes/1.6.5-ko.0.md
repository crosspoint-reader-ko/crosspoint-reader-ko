## 요약

upstream **v1.6.5**를 병합한 한국어 버전입니다. 서재 화면, 글자·단어 간격 조절, 시계와 시간대, 각주 이동 개선이 들어왔습니다. 한국어 전용 글꼴·조판 기능은 모두 그대로 유지했습니다.

> [!IMPORTANT]
> **섹션 캐시 포맷이 v42 → v49로 바뀌어 모든 책이 한 번 다시 색인됩니다.** 첫 열기가 평소보다 느린 것은 정상입니다.

## upstream v1.6.0 / v1.6.5 주요 변경 사항

### 기능
* **서재**: 최근 책 화면이 SD 카드 전체를 보는 서재로 바뀌었습니다. 최근 추가, 제목, 저자 순으로 정렬하고 검색할 수 있습니다.
* **글자 간격·단어 간격**: 리더 설정에서 글자 사이(-2~+2 px)와 단어 사이(50~200%) 간격을 조절합니다.
* **시계**: 홈 화면과 헤더에 시계를 표시합니다. UTC 오프셋 대신 도시 목록에서 시간대를 고르고, 일광 절약 시간은 자동으로 처리합니다.
* **각주 이동 개선**: 페이지 안의 각주 참조를 강조해 고를 수 있습니다.
* **책갈피 이름 바꾸기**, **파일 이름 바꾸기**(파일 탐색기).
* **야간 모드**: 읽는 동안 화면을 반전합니다.
* **"아주 넓게" 줄 간격** 추가.
* **정보 화면**: 설정 > 시스템에서 기기 정보를 봅니다.
* **사전**: StarDict `.syn` 동의어 검색, HTML 정의를 EPUB 엔진으로 그립니다.
* **EPUB 표**를 열 단위로 배치하고, 번호 목록에 번호를 붙입니다.
* 투명 PNG/BMP 절전 오버레이(`.sleep-overlay` 폴더), 절전 화면 회색조 품질 개선.

### 수정 / 성능
* 글꼴·EPUB 메모리 사용과 힙 단편화를 줄였습니다.
* 짧은 버튼 입력이 누락되던 문제, 목록 스크롤, 책 끝 메뉴 선택 등을 고쳤습니다.
* 첫 페이지를 그리지 못한 EPUB을 깨어날 때 다시 열지 않습니다.
* 웹 파일 전송에서 경로를 정규화해 안전성을 높였습니다.

## 한국어 버전 변경 사항

### 기능
* **지원 기기 확대**: X3/X4 외에 Seeed reTerminal Sticky, X4 Pro, X4 Classic, M5Stack Paper Mono용 한국어 펌웨어를 함께 배포합니다. 기기별 파일은 `crosspoint-1.6.5-ko.0-<기기>.bin`(OTA·SD 업데이트)과 `CrossPoint-1.6.5-ko.0-<기기>-full.bin`(전체 플래시 이미지)입니다.
* 새 글자·단어 간격 설정이 한국어 글자 단위 줄바꿈에도 적용됩니다.
* 리더 도구 막대의 "글자" 패널에서 한국어 글꼴 선택과 읽기 옵션을 엽니다.

### 수정
* **홈 화면 이어서 읽기**: 책 제목이 여러 줄로 줄바꿈되지 않고 한 줄로 표시되며, 길면 말줄임(…)으로 줄입니다. 한글·영문 제목 모두 같습니다.

### 유지된 한국어 전용 기능
* `UnifiedFontFamily` / `SdFontFamily` 글꼴 시스템 (SD 카드 `.epdfont` 런타임 로딩)
* 기본 EPUB 글꼴 KoPub 바탕, UI 시스템 글꼴 선택 + Pretendard 글리프 폴백
* 합성 볼드 렌더링, 자간 조절
* 단락 들여쓰기 / 글자 단위 줄바꿈 (기본 켜짐), 한국어 줄 간격 1.00 / 1.20 / 1.40배 (+ 아주 넓게 1.60배)
* 하이픈은 글자 단위 줄바꿈이 꺼져 있을 때만 적용
* 읽기 시간 누적·초기화, 자동 페이지 넘김, 길게 눌러 페이지 점프, 읽기 옵션
* 절전 이미지 선택, 배터리 표시 보정
* X4 2단계 OTA 경로 (SD 다운로드 후 플래시)

### 바뀐 동작
* **TXT 책 끝**: 마지막 페이지에서 넘기면 홈으로 가지 않고 책 끝 화면이 나옵니다. EPUB·XTC와 같은 동작입니다.

### 포함하지 않은 upstream 기능
* `.cpfont` SD 글꼴 엔진, 글꼴 다운로드, 텍스트 설정 화면, 웹 글꼴 페이지 (한국어 `.epdfont` 엔진 유지)
* TTF 글꼴 (PSRAM 보드 전용, upstream 글꼴 엔진 기반)
* 불가리아어·페르시아어 등 다른 UI 언어 (한국어·영어만 포함)

자세한 상충 지점과 처리 내용: `docs/release-notes/1.6.5-ko.0-merge-conflicts.md`
