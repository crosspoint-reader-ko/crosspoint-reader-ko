## 요약

1.6.5-ko.1의 수정 릴리스입니다. 파일 이름의 숫자 정렬, 파일 탐색기와 다음 권 안내의 긴 파일명 표시, 홈 화면 버튼 안내의 줄바꿈을 고쳤습니다.

## 한국어 버전 변경 사항

### 수정
* **숫자가 든 파일 이름 정렬**: 점으로 나뉜 숫자를 자리별로 비교합니다. `5권 < 5.5권 < 6권`, `1.2 < 1.10` 순서로 정렬되고, 다음 권 찾기도 같은 순서를 따릅니다. 대소문자나 앞자리 0만 다른 같은 이름은 다음 권 후보에서 뺍니다. (@Meatholic)
* **파일 탐색기**: 긴 파일 이름이 두 줄로 나와도 잘리지 않도록 행 높이를 두 줄 기준으로 잡습니다.
* **다음 권 안내**: 책 끝 화면의 다음 권 파일 이름을 말줄임 대신 두 줄로 보여 줍니다.
* **홈 화면 버튼 안내**: Lyra 테마에서 "이어 읽기" 버튼 안내가 두 줄로 나뉘던 것을 한 줄로 고쳤습니다.

### 업데이트 방법

- **OTA**: WiFi 연결 후 설정 → 시스템 → 업데이트
- **SD**: X3/X4는 `firmware.bin`, 다른 기기는 `crosspoint-1.6.5-ko.2-<기기>.bin`을 SD 카드에 복사 → 설정 → 시스템 → SD카드 펌웨어 업데이트
- **웹 플래셔**: https://crosspoint.kr/flasher
- 설치 가이드: https://crosspoint.kr/install
