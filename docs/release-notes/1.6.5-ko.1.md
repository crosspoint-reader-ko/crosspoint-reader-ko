## 요약

1.6.5-ko.0의 수정 릴리스입니다. X4 Pro 같은 터치 기기에서 한국어 버전 전용 화면을 손가락으로 조작할 수 있게 했고, 홈 화면의 책 제목이 모든 테마에서 한 줄로 나오게 고쳤습니다.

## 한국어 버전 변경 사항

### 수정
* **터치 기기 지원**: 한국어 버전에만 있는 화면은 버튼으로만 움직였고, 터치 기기에서는 버튼 안내가 숨겨져 빠져나갈 방법도 없었습니다. 이제 다른 화면과 같은 방식으로 터치를 받습니다.
  * **글꼴 선택 / 시스템 글꼴 선택**: 목록에서 글꼴을 눌러 바로 적용합니다. 지금 쓰는 글꼴에 "선택됨"이 표시됩니다.
  * **절전 화면 선택**: 그림을 누르면 선택이 바뀌고, 좌우로 밀어 다음 그림으로 넘어갑니다. 아래쪽 칸에 선택 상태, 위쪽에 순서(예: 1 / 3)가 나옵니다.
  * **TXT 리더 메뉴**: 항목을 눌러 실행합니다. 화면 방향, 자동 넘김, 길게 눌러 페이지 이동은 EPUB 메뉴처럼 선택 창에서 고릅니다.
  * 네 화면 모두 왼쪽 위 뒤로 화살표로 나갑니다. 측면 버튼 조작은 그대로입니다.
* **홈 화면 책 제목**: 이어서 읽기와 최근 책 제목이 모든 홈 테마에서 한 줄로 표시되고, 길면 말줄임(…)으로 줄입니다. 한글·영문 제목 모두 같습니다.

### 업데이트 방법

- **OTA**: WiFi 연결 후 설정 → 시스템 → 업데이트
- **SD**: X3/X4는 `firmware.bin`, 다른 기기는 `crosspoint-1.6.5-ko.1-<기기>.bin`을 SD 카드에 복사 → 설정 → 시스템 → SD카드 펌웨어 업데이트
- **웹 플래셔**: https://crosspoint.kr/flasher
- 설치 가이드: https://crosspoint.kr/install
